# 도쿄, 함께 걷기 · TOKYO FAMILY CONCIERGE 2026 (v3.0)

2026년 11월 22일(일)~11월 25일(수) 3박 4일 도쿄 첫 방문 가족 여행을 위한 프리미엄 스마트 컨시어지 웹 애플리케이션입니다. (1일차 스카이트리 전망대 야경, 24곳 현장 실물사진, 디즈니씨 25주년 마스터 공략 센터, 도쿄 생존·긴급 SOS 및 2026년 11월 최신 면세·디즈니 규정 전면 반영)

## 활용된 오픈소스 프레임워크 및 GitHub 라이브러리

- **React 18 (`facebook/react`) & Vite (`vitejs/vite`)**: 컴포넌트 기반 모던 SPA 아키텍처 및 `manualChunks` 코드 스플리팅 빌드
- **Zustand (`pmndrs/zustand`)**: `persist` 미들웨어 기반 중앙 영속 상태 스토어 (`tokyo-trip-store-v3`, 기존 v1 데이터 자동 마이그레이션)
- **Recharts (`recharts/recharts`)**: 디즈니씨 시간대별 예상 대기시간 예측 곡선 및 일차별 가족 여행 예산/지출 차트
- **Fuse.js (`krisk/Fuse`)**: 일정·실물사진·일본어 회화 오타 허용 통합 스마트 퍼지 검색
- **Sonner (`emilkowalski/sonner`)**: 비동기 오프라인 캐시·DPA 타이머·백업 알림용 리치 토스트 시스템
- **React Error Boundary (`bvaughn/react-error-boundary`)**: 최상위 앱 렌더링 장애 시 저장 데이터 보호 및 원클릭 복구 UI
- **Tailwind CSS (`tailwindlabs/tailwindcss`)**: 부티크 에디토리얼 디자인 시스템 및 다크(야경) 테마 지원
- **Framer Motion (`framer/motion`)**: 부드러운 타임라인 카드 트랜지션
- **Leaflet (`Leaflet/Leaflet`)**: 1~4일차 전체 동선 폴리라인(Polyline), 번호 마커, 세부 관심 지점, 내 현재 위치(GPS) 및 Google 지도 내비게이션을 연동한 실시간 인터랙티브 지도
- **React-Zoom-Pan-Pinch (`BetterTyped/react-zoom-pan-pinch`)**: 마우스 휠, 터치 핀치, 더블클릭으로 최대 500%까지 부드럽게 확대·패닝할 수 있는 원본 동선지도 6장 딥줌(Deep-Zoom) 뷰어
- **Lucide Icons (`lucide-icons/lucide`)**: 직관적인 교통·여행·컨시어지 벡터 아이콘 시스템
- **Canvas Confetti (`catdad/canvas-confetti`)**: 일정 및 준비물 체크리스트 완료 시 축하 파티클 효과

## 주요 기능

1. **여행 일정 & 스마트 타임라인**:
   - 원본 Word 문서(`도쿄여행 일정.docx`)의 전체 64문단, 4일간 19개 시간 구간(1일차 스카이트리 350m·450m 전망대 야경 관람 포함) 100% 보존
   - 도쿄 지하철 5대 노선 공식 색상 배지 (`Z` 한조몬선, `A` 아사쿠사선, `G` 긴자선, `H` 히비야선, `JE` JR 게이요선) 및 무환승 경로 시각화
   - 일본어 현지 지명 표기 및 원어민 음성 발음 재생(Web Speech API TTS)
   - 도쿄 첫 방문 가족 맞춤형 실전 컨시어지 팁 및 날짜별 메모 자동 저장
2. **현장 실물사진 가이드 (24곳) & 타임라인 양방향 연동**:
   - 나리타 T3 도착·리무진 매표소·승강장·T-CAT 하차장, 예약 숙소 **S-페리아 인 니혼바시 하코자키** 3각도(입구 간판·건물 전경·1층 로비), PASMO 자동발매기, 탑승·하차 전철역, 스카이트리 4층 입구·전망대 야경, 디즈니씨까지 24곳의 실제 현장 실물사진(Wikimedia Commons CC/PD & 공식 호텔 사진)과 단계별 행동 요령 제공
   - 타임라인 카드 내 실물사진 썸네일 스트립, 전체화면 라이트박스(멀티 각도 전환 지원), 예약번호·객실 메모 저장 및 PWA 오프라인 캐시(`tokyo-concierge-v8`) 지원
3. **듀얼 동선지도 센터 (Interactive GPS + 6 Original Maps)**:
   - **실시간 인터랙티브 지도**: 일차별 동선 폴리라인, 순서 핀, 스카이트리 4층 입구·광장 등 주요 포토존/식당 보조 마커 및 Google 지도 길찾기 연동
   - **원본 동선지도 6장 딥줌 뷰어**: `route-1.png` ~ `route-6.png` 원본 무손실 보존 및 고배율 팬/줌, PNG 다운로드 지원
4. **도쿄 첫 방문 가족 실전 컨시어지 (5대 툴킷)**:
   - **디즈니씨 25주년 & 크리스마스 마스터 공략 센터**: DPA 60분 쿨다운 타이머, Recharts 시간대별 대기시간 예측 곡선, 전날 밤 5단계 체크보드, 10종 어트랙션 우선순위 매트릭스, 모바일 오더 식당 3선, 25주년 쇼·운휴·우천 플랜 B·미아 합류 안내 및 당일 9단계 타임보드
   - **도쿄 첫 방문 생존 · 매너 · 긴급 SOS 센터**: 110/119/대사관/영사콜센터/관광청 원터치 전화·복사, 택시 T-CAT/스이텐구마에 전체화면 복귀 포인팅 카드, 2026.11 신 면세 환급제 4단계, 지하철 5대 함정 및 생활 팁 5종
   - **서바이벌 일본어 & 점원 포인팅 카드**: 9개 카테고리 16종 회화(스카이트리 전망대·호텔 체크인·디즈니 모바일 오더·택시 SOS 포함) 원어민 음성 재생 및 전체화면 큰 글씨 보여주기 모드 지원
   - **지하철 5대 노선 & 무기명 PASMO·2026.11 신 면세 가이드**: 역 번호·방면 요약 및 PASMO 구매·잔액 소진법, 신 면세 환급제 안내
   - **엔화(JPY) ↔ 원화(KRW) 환율 계산기 & 가족 가계부**: 기준 금액 원터치 환산(스카이트리 350m/세트·DPA 포함), Recharts 일차별 지출 분포 차트 및 카테고리별 지출 관리
5. **스마트 준비 체크리스트 & 원본 문서 아카이브**:
   - 원문+첫 방문 필수 항목 기반 18개 체크리스트(110V 어댑터/eSIM, 디즈니 그룹·해외결제 카드, 스카이트리 사전예약 포함) + 가족 커스텀 준비물 추가, JSON 백업/복원(Zustand `tokyo-trip-store-v3` 영속 저장 및 v1 자동 마이그레이션)
   - 원본 Word 문서 전체 64문단 열람, 문단 검색 및 `.docx` 원본 다운로드

## 실행 및 빌드 방법

배포된 정적 파일은 `dist/` 폴더에 포함되어 있습니다. 로컬에서 바로 실행하려면:

```bash
python -m http.server 4317 --bind 127.0.0.1 --directory dist
```

또는 개발 서버/재빌드를 실행하려면:

```bash
npm install
npm run dev    # http://127.0.0.1:4317
npm run build  # dist/ 폴더에 정적 프로덕션 번들 생성
```
