# 도쿄, 함께 걷기

2026년 11월 22~25일 가족 여행을 위한 웹앱입니다.

- 원본 일정 문서의 전체 60문단, 4일간 18개 시간 구간
- 동선지도 6장 원본 확대·다운로드 (4일차 지도는 원문에 없음)
- 전체 일정 검색, 방문 완료 체크, 준비 체크리스트 15개
- 날짜별 메모 자동 저장, 일정·지도 오프라인 저장
- 원본 Word 문서 내려받기, 휴대폰 홈 화면 추가 지원

## 사용

배포된 앱 주소로 접속하세요. 체크와 메모는 접속한 브라우저에 저장되며 기기 간 자동 동기화되지 않습니다. 여행 전에 '오프라인 저장'을 누르고 완료 표시를 확인하세요. 외부 지도 검색은 인터넷이 필요합니다. 브라우저가 저장된 사이트 데이터를 삭제하면 오프라인 자료 및 기록도 사라질 수 있습니다.

로컬에서 실행할 경우 이 폴더에서 다음 명령을 실행한 뒤 http://127.0.0.1:4317 을 여세요.

    python -m http.server 4317 --bind 127.0.0.1 --directory dist

'원본 일정' 화면과 지도는 제공된 자료를 그대로 보존합니다. 요금·운영시간·휴장·면세 제도는 원문 작성 기준이며 최신 정보로 검증한 내용이 아닙니다. 디즈니씨 지도는 실제 거리·모양과 다른 약도입니다. 숙소명과 항공편 번호는 원문에 없어 추가하지 않았습니다.

## 파일

앱은 dist 폴더의 정적 파일로 동작합니다. data.js는 원문에서 추출한 일정 데이터, assets/route-1.png~route-6.png는 변경하지 않은 원본 지도입니다. source-itinerary.txt에 추출 원문이 있습니다.
